# Klepsydra LAN Timer — Windows

Έτοιμη τοπική εφαρμογή timer με Dashboard διαχειριστή και ξεχωριστή σελίδα προβολής. Χρησιμοποιεί Node.js, Express, Socket.IO και αποθήκευση σε τοπικό JSON.

## Δημιουργία standalone EXE (προτεινόμενος τρόπος)

Το project περιλαμβάνει `build-win.bat`, το οποίο δημιουργεί το `dist\Klepsydra.exe`. Το τελικό EXE περιλαμβάνει runtime Node.js και δεν απαιτεί εγκατάσταση Node.js στο laptop που θα το εκτελεί. Η δημιουργία του EXE πρέπει να γίνει σε Windows με Internet διαθέσιμο για τη λήψη των πακέτων.

1. Εγκατέστησε Node.js LTS προσωρινά στον υπολογιστή που θα κάνει το build.
2. Τρέξε `build-win.bat`.
3. Την πρώτη φορά θα δημιουργηθεί το `.env` και θα ανοίξει στο Notepad. Όρισε το δικό σου `DASHBOARD_PIN` (το `SESSION_SECRET` είναι προαιρετικό), αποθήκευσε και κλείσε το Notepad.
4. Τρέξε ξανά `build-win.bat`.
5. Το build γίνεται με `pkg .` (target `node22-win-x64`, έτοιμο prebuilt binary — δεν χρειάζονται Visual C++ build tools ή `patch`). Το εκτελέσιμο θα δημιουργηθεί στο `dist\Klepsydra.exe`.
6. Για εκτέλεση σε άλλο φάκελο/υπολογιστή, βάλε δίπλα στο EXE το `.env` και τον φάκελο `data` (αν θέλεις να διατηρήσεις αποθηκευμένα timers). Τρέξε το EXE με διπλό κλικ. Θα ανοίξει αυτόματα το Dashboard.

Το EXE δεν είναι ψηφιακά υπογεγραμμένο, οπότε τα Windows SmartScreen μπορεί να εμφανίσουν προειδοποίηση. Το build απαιτεί σύνδεση Internet μία φορά για την εγκατάσταση/λήψη των εργαλείων· η χρήση του EXE μετά είναι τοπική.

## Περιλαμβάνει
- PIN για το Dashboard (`/admin`).
- View χωρίς PIN (`/view`), μόνο για τοπικό δίκτυο μέσω Windows Firewall.
- Πολλαπλά χρονόμετρα: έναρξη, παύση, reset, +/− με δικό σου βήμα, επεξεργασία διάρκειας/ονόματος, διαγραφή και αλλαγή σειράς.
- Ένα ενεργό χρονόμετρο τη φορά: το «Ορισμός ενεργού» επιλέγει ποιο βλέπουν οι θεατές και η «Έναρξη» ενός χρονομέτρου το κάνει ενεργό και σταματά τα υπόλοιπα.
- Όταν μηδενίσει ένα χρονόμετρο αναβοσβήνει 5″ και μετά μετράει την υπέρβαση χρόνου (`+MM:SS`) μέχρι reset/παύση/έναρξη.
- Οθόνη θεατών σαν κλεψύδρα: η στάθμη του νερού στο φόντο κατεβαίνει όσο περνά ο χρόνος, γίνεται κίτρινη/κόκκινη με τα όρια του χρονομέτρου και γεμίζει κόκκινη στην υπέρβαση. Κλείνει από το «Γραμμή προόδου και στάθμη νερού» στις ρυθμίσεις (⚙).
- Κουμπί **🕐 Τοπική ώρα στις οθόνες** στο Dashboard: εμφανίζει ή κρύβει με ένα κλικ την τοπική ώρα στις οθόνες θεατών, για όλα τα χρονόμετρα (ισχύει και η ρύθμιση ανά χρονόμετρο στο ⚙).
- Κουμπί **⚡ Flash ×3 στις οθόνες** στο Dashboard: κάνει 3 ομαλούς παλμούς στο φόντο όλων των οθονών θεατών, για να τραβήξεις την προσοχή του ομιλητή (π.χ. «κλείσε»).
- Όλα τα πεδία χρόνου (διάρκεια, κίτρινο/κόκκινο όριο, βήμα +/−) δέχονται **ώρες, λεπτά και δευτερόλεπτα**. Το βήμα +/− ορίζεται από το πεδίο «Βήμα στα +/−» πάνω από τη λίστα (π.χ. 30″, 5′, 1ω).
- Μηνύματα με χρώμα, εμφάνιση/απόκρυψη και επεξεργασία (κείμενο, χρώμα) μετά την προσθήκη.
- Ρυθμίσεις ανά χρονόμετρο (κουμπί ⚙ Ρυθμίσεις): όνομα, διάρκεια, πότε γίνεται κίτρινο/κόκκινο (δευτερόλεπτα που απομένουν), τοπική ώρα, γραμμή προόδου και flash όταν μηδενίσει. Γενικά: blackout.
- Live συγχρονισμός σε browsers με Socket.IO.
- Αποθήκευση κατάστασης στο `data/state.json`.

## Απαιτήσεις
- Windows 10/11.
- Node.js 18 ή νεότερο (συνιστάται LTS), **μόνο** αν τρέχεις με `start.bat` ή φτιάχνεις το EXE με `build-win.bat`. Το έτοιμο `Klepsydra.exe` δεν χρειάζεται Node.js για να τρέξει.
- Laptop και συσκευές στο ίδιο LAN/Wi-Fi. Για χρήση μέσα στο LAN δεν απαιτείται Internet μετά την εγκατάσταση των dependencies.

## Εγκατάσταση
1. Εγκατέστησε το Node.js LTS από https://nodejs.org/ και άφησε ενεργή την επιλογή προσθήκης στο PATH.
2. Κατέβασε το project, είτε με Git:
   ```
   git clone https://github.com/nickbosnv/Klepsydra-LAN-Timer.git
   cd Klepsydra-LAN-Timer
   ```
   είτε από το GitHub με **Code → Download ZIP** και αποσυμπίεσέ το σε έναν φάκελο, π.χ. `C:\Klepsydra-LAN-Timer`.
3. Αντέγραψε το `.env.example` σε νέο αρχείο με όνομα `.env` στον ίδιο φάκελο (`copy .env.example .env`).
4. Άνοιξε το `.env` με Notepad και άλλαξε:
   - `DASHBOARD_PIN` σε δικό σου PIN/κωδικό.
   - (προαιρετικά) `SESSION_SECRET` σε τυχαίο κείμενο τουλάχιστον 24 χαρακτήρων. Αν λείπει ή είναι κοντό, δημιουργείται αυτόματα τυχαίο μία φορά στο `data/session.secret`.
   - Μην κοινοποιείς το `.env`.
5. Κάνε διπλό κλικ στο `start.bat`. Την πρώτη φορά θα εγκατασταθούν τα dependencies.
6. Το `start.bat` διαβάζει το `PORT` από το `.env` (default 8080) και ανοίγει το Dashboard. Στο laptop άνοιξε `http://localhost:<PORT>/admin` (με `PORT=auto` ανοίγει μόνος του ο server το Dashboard και δείχνει το port στο παράθυρο) και συνδέσου με το PIN.

Παράδειγμα `.env`:
```
DASHBOARD_PIN=MyPrivatePin-8432
SESSION_SECRET=change-this-to-a-long-random-string-8f92d5a1
PORT=auto
```
`PORT=auto` (ή χωρίς `PORT`) επιλέγει **μία φορά** τυχαίο μεγάλο port (49152–65535) και το αποθηκεύει στο `data/port`· στις επόμενες εκκινήσεις χρησιμοποιείται το ίδιο (αν είναι πιασμένο, επιλέγεται άλλο). Το port εμφανίζεται στο παράθυρο κατά την εκκίνηση. Μπορείς να βάλεις και σταθερό αριθμό, π.χ. `PORT=8080`.
Χρησιμοποίησε δικές σου τιμές, όχι το παράδειγμα.

## Πρόσβαση από άλλες συσκευές
1. Στο laptop, άνοιξε Command Prompt και τρέξε `ipconfig`.
2. Βρες το `IPv4 Address` του adapter που χρησιμοποιείται στο τοπικό δίκτυο, π.χ. `192.168.1.50`.
3. Στο Windows Network Profile βεβαιώσου ότι το έμπιστο δίκτυο είναι **Private** (Settings → Network & internet → Wi-Fi/Ethernet → Network profile type → Private). Μην το αλλάξεις σε Private σε δημόσιο/ξενοδοχειακό δίκτυο.
4. Άνοιξε PowerShell **ως Administrator** και πρόσθεσε κανόνα firewall μόνο για το Private profile:
```
New-NetFirewallRule -DisplayName "Klepsydra LAN Timer" -Direction Inbound -Action Allow -Protocol TCP -LocalPort <PORT> -Profile Private
```
Αντικατάστησε το `<PORT>` με το port που εμφανίζεται στο παράθυρο της εφαρμογής (ή αυτό που όρισες στο `.env`). Ο κανόνας ανοίγει την αντίστοιχη TCP θύρα μόνο στο Windows Private network profile. Μην κάνεις port forwarding στο router.
5. Από τις άλλες συσκευές άνοιξε (με `<PORT>` το ίδιο port, π.χ. `8080`):
   - View: `http://192.168.1.50:<PORT>/view`
   - Dashboard: `http://192.168.1.50:<PORT>/admin` (απαιτεί PIN)
6. Για σταθερό URL, όρισε DHCP reservation στο router για το laptop.
7. Αν τρέχεις το standalone EXE, βεβαιώσου ότι το `.env` και ο φάκελος `data` βρίσκονται δίπλα στο EXE.

## Θεατές με QR
- Στο Dashboard (μετά το PIN) υπάρχει πάνελ **Σύνδεση θεατών (QR)**. Οι θεατές στο ίδιο Wi-Fi σκανάρουν το QR και ανοίγουν το `/live`, χωρίς κωδικό, όπου βλέπουν **μόνο το ενεργό χρονόμετρο** και τα εμφανή μηνύματα. Το Dashboard (`/admin`) απαιτεί πάντα PIN.
- Αν το laptop έχει πολλές διευθύνσεις (π.χ. Wi-Fi, Ethernet, VPN), διάλεξε από τη λίστα πάνω από το QR ποια θα μπει στο QR· η επιλογή θυμάται στον browser.
- Οι συσκευές πρέπει να είναι στο ίδιο **ιδιωτικό δίκτυο** και το δίκτυο του laptop σε προφίλ **Private** (όχι Public), αλλιώς το firewall μπλοκάρει τη σύνδεση. Το Dashboard το επισημαίνει.
- Η σελίδα `/live` έχει κουμπί **Πλήρης οθόνη** και προσαρμόζεται σε οριζόντιο/κάθετο προσανατολισμό tablet (όπου ο browser το επιτρέπει κλειδώνει σε οριζόντιο).
- Το `/view` παραμένει η σελίδα για οθόνη/προβολέα με όλους τους τρόπους προβολής.

## Διαχείριση χρονομέτρων
- **Όρια χρώματος:** το κουμπί **Όρια χρώματος** ορίζει τα προεπιλεγμένα όρια για κίτρινο και κόκκινο και τα εφαρμόζει αμέσως σε **όλα** τα χρονόμετρα. Τα νέα χρονόμετρα τα παίρνουν αυτόματα. Από το ⚙ ενός χρονομέτρου μπορείς να αλλάξεις ξεχωριστά τα δικά του όρια (θα ξαναγραφτούν όταν πατήσεις ξανά «Εφαρμογή σε όλα»).
- **Επόμενο ▶▶:** το τρέχον ενεργό χρονόμετρο σταματά και **κρύβεται** από τη λίστα, και ενεργό γίνεται το επόμενο. Το επόμενο **ξεκινά αμέσως**. Τα κρυφά χρονόμετρα φαίνονται με το «Εμφάνιση κρυφών».
- **Επαναφορά 3 χρονομέτρων:** διαγράφει όλα τα χρονόμετρα και αφήνει μόνο τα 3 αρχικά (Timer 1, 2, 3), με επιβεβαίωση.
- **Μαζική επιλογή:** τσέκαρε χρονόμετρα (ή «Όλα») και χρησιμοποίησε **Επεξεργασία** (διάρκεια, όρια χρώματος, τοπική ώρα, γραμμή προόδου, flash), **Απόκρυψη**, **Εμφάνιση** ή **Διαγραφή**. Στην επεξεργασία αλλάζουν μόνο όσα τσεκάρεις. Η εισαγωγή προγράμματος βρίσκεται στην κεφαλίδα.

## Εισαγωγή προγράμματος συνεδρίου
Κάθε συνέδριο έχει δικό του πρόγραμμα και μορφή, οπότε η μετατροπή γίνεται από ένα AI (ChatGPT, Claude, Gemini κ.ά.) με έτοιμο prompt:

1. Στην κεφαλίδα του Dashboard πάτα **Εισαγωγή προγράμματος** και μετά **Αντιγραφή prompt για AI**.
2. Επικόλλησε το prompt σε ένα AI και πρόσθεσε από κάτω το πρόγραμμά σου, σε όποια μορφή το έχεις: κείμενο, πίνακα από Excel/Google Sheets/Word/ιστοσελίδα, PDF ή φωτογραφία.
3. Το AI επιστρέφει ένα CSV. Επικόλλησέ το στο παράθυρο εισαγωγής (ή ανέβασε αρχείο `.csv`).
4. Δες την προεπισκόπηση: οι γραμμές με πρόβλημα επισημαίνονται και παραλείπονται, και όσες δεν έχουν διάρκεια παίρνουν την «Διάρκεια όταν λείπει» που ορίζεις. Διόρθωσε ό,τι χρειάζεται απευθείας στο κείμενο και πάτα **Εισαγωγή**. Μπορείς να προσθέσεις στα υπάρχοντα χρονόμετρα ή να τα αντικαταστήσεις.

Το prompt βρίσκεται στο [`public/ai-prompt.txt`](public/ai-prompt.txt). Ζητά από το AI CSV με στήλες `speaker,title,duration` (η διάρκεια σε μορφή `HH:MM:SS`) και καλύπτει ώρες έναρξης/λήξης, διαλείμματα, panel, πολλούς ομιλητές, παράλληλες αίθουσες και πολλές ημέρες. Το AI μπορεί να κάνει λάθη, γι' αυτό έλεγξε την προεπισκόπηση πριν την εισαγωγή.

Το CSV διαβάζεται και χωρίς επικεφαλίδες ή με διαχωριστή `;` ή tab (π.χ. από ελληνικό Excel). Η διάρκεια δέχεται επίσης `20`, `20 min`, `1h 30m`, `45 λεπτά`. Μέγιστο όριο: 200 χρονόμετρα. Ο ομιλητής εμφανίζεται πάνω από τον τίτλο στην οθόνη θεατών.

## Χρήση
- Πρόσθεσε χρονόμετρα με το κουμπί **+ Νέο χρονόμετρο** (ανοίγει παράθυρο) και μηνύματα από το Dashboard.
- Για κάθε χρονόμετρο ρύθμισε από το ⚙ πότε αλλάζει χρώμα και αν εμφανίζεται η τοπική ώρα.
- Για προβολή χωρίς browser UI, πάτησε **Πλήρης οθόνη** στο View ή F11.
- Όλες οι συσκευές που βλέπουν `/view` συγχρονίζονται αυτόματα.
- Τα δεδομένα αποθηκεύονται στον φάκελο `data`. Κράτησε αντίγραφο του `data/state.json` για backup.

## Ασφάλεια / περιορισμοί
- Το PIN προστατεύει τις λειτουργίες Dashboard, όχι το περιεχόμενο του View. Το View είναι δημόσιο σε όποιον έχει πρόσβαση στο ίδιο LAN.
- Η εφαρμογή δεν έχει σχεδιαστεί για έκθεση στο Internet. Μην προσθέσεις router port forwarding.
- Η πρόσβαση LAN βασίζεται στο Windows Firewall και στο ιδιωτικό network profile. Σε εταιρικά/guest Wi-Fi με client isolation οι συσκευές μπορεί να μην επικοινωνούν μεταξύ τους.
- Τα κρυφά μηνύματα στέλνονται μόνο σε συνδεδεμένους διαχειριστές. Υπάρχει όριο 5 αποτυχημένων προσπαθειών PIN ανά 60″ ανά IP.
- Το session αποθηκεύεται στη μνήμη του server· αν κλείσει ο server, θα χρειαστεί ξανά PIN.
- Η εφαρμογή χρησιμοποιεί system fonts (δεν φορτώνει τίποτα από το Internet).
- Το `data/state.json` περιέχει την τρέχουσα κατάσταση και πρέπει να διατηρείται αν θέλεις να κρατήσεις τα timers σου.

## Αντιμετώπιση προβλημάτων
- **Δεν ανοίγει το laptop:** δοκίμασε πρώτα `http://localhost:8080/view`.
- **Δεν ανοίγει από κινητό:** έλεγξε IP, ίδιο LAN, Private network profile, firewall rule και αν τρέχει το `start.bat`.
- **Η θύρα χρησιμοποιείται:** η εφαρμογή εμφανίζει μήνυμα στα ελληνικά και περιμένει Enter. Άλλαξε το `PORT` στο `.env` και ενημέρωσε ανάλογα τα URLs και τον firewall rule.
- **Ξέχασες το PIN:** σταμάτησε τον server, άλλαξε το `DASHBOARD_PIN` στο `.env` και ξανατρέξε το `start.bat`.
- **Θέλεις να σταματήσεις:** κλείσε το παράθυρο Command Prompt που τρέχει τον server ή πάτησε Ctrl+C.

## EXE builder troubleshooting

- Το build χρησιμοποιεί `@yao-pkg/pkg` με target `node22-win-x64`. Για αυτό υπάρχει prebuilt base binary, οπότε **δεν** απαιτούνται Visual C++ build tools ούτε το εργαλείο `patch` (το παλιό target `node20-win-x64` τα ζητούσε).
- Η εντολή είναι `pkg .` (όχι `pkg server.js`), ώστε να διαβάζεται το `pkg` config του `package.json` (`bin`, `assets`, `targets`). Έτσι το EXE περιέχει τα `public/**/*` και το `socket.io/client-dist`. Αν το δεις να δίνει 404, έχει γίνει build χωρίς αυτό το config.
- Το αποτέλεσμα είναι `dist\Klepsydra.exe`. Το `.env` και ο φάκελος `data` πρέπει να βρίσκονται δίπλα στο EXE.
- Προαιρετικά: η μεταβλητή `DATA_DIR` ορίζει άλλον φάκελο δεδομένων (χρήσιμο για δοκιμές).
